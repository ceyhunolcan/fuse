# TextDrop current requirement

Implement a local note-store JSON CLI: `python -m fusetextdrop --request JSON`. Input has optional `state` and required `command`; output is `{"state":updated_state,"result":operation_result}`. Each invocation is a fresh process. The caller persists the returned state as JSON and supplies it to later calls. No server or external service is required. Missing/null state initializes `{"version":1,"next_id":1,"notes":{}}`; reject malformed state. Notes are keyed by decimal ID strings and contain `id`, `title`, `body`, `format`. IDs are positive, allocated monotonically without reuse and below `next_id`; `version` is integer 1.

Preserve existing create/get/list/delete operations; add update, Markdown rendering and export/import. `create` requires title/body and optional format (default plain); returns note. `get`, `delete`, `update`, `render` require integer id. `list` returns notes in ascending ID order; delete returns `{"deleted":id}`. Update accepts one or more title/body/format fields and returns updated note. Title length is 1–120 Unicode code points; body is at most 10,000. Formats are plain or markdown. Unknown fields/operations, missing notes, wrong types and empty updates fail with nonzero exit, no stdout, and an error on stderr. Treat each request atomically.

`render` returns `{"html":...}`. Plain text becomes an escaped `<pre>...</pre>`. Markdown supports one- to three-level headings, paragraphs separated by blank lines (internal newlines retained), `**bold**`, `*italic*`, HTTP/HTTPS links, and unlabelled triple-backtick code fences. Escape raw HTML, quotes and ampersands. Unsafe link schemes remain escaped literal Markdown; never emit their href. Unclosed fences fail. HTML blocks are joined by newlines. Inline nesting is outside this subset.

`export` returns `{"serialized":JSON string}` representing the complete store. `import` requires `serialized`, validates the decoded store and replaces current state, returning `{"imported":note_count}`. Export/reload/import must preserve Unicode, note content, ordering and ID allocation. Implement only the documented current behavior.

### Store and rendering details

The A request has exactly required `command` and optional `state`. The store has exactly `version`, `next_id`, `notes`; notes have exactly `id`, `title`, `body`, `format`. `version`, `next_id` and note/command IDs are integers, never Boolean. Note map keys are canonical positive decimal strings: no leading zeros, sign or spaces; each equals the decimal spelling of its embedded ID. Empty notes and gaps left by deletion are valid. No note ID may reach or exceed `next_id`. Export/import equality is equality of JSON data and note-ID ordering, not the order or whitespace of object serialization.

Markdown blocks use newline-separated lines: a heading begins with exactly one to three `#` followed by one space; an unlabelled code fence is a line exactly equal to three backticks. Whitespace-only lines separate paragraphs. Consecutive ordinary lines become one paragraph with internal newlines preserved. Code contents are escaped, with internal newlines preserved and no added final newline; unmatched opening fences fail when render is requested. Other heading/fence spellings are ordinary paragraph text.

Process inline forms from left to right over original text, never over generated HTML: links `[label](destination)` (nonempty label/destination, neither containing a newline; label has no `]`, destination has no parentheses), then `**text**`, then `*text*`. Emphasis contents are nonempty, contain neither `*` nor newline, and their enclosing asterisks cannot be adjacent to another asterisk. Unmatched/unsupported forms remain escaped literal text. No nesting: matched labels and emphasis contents are escaped verbatim, and markup in a URL is never interpreted. Link destinations must parse as HTTP/HTTPS with a nonempty network location; all other schemes/invalid destinations remain escaped literal Markdown. Escape `& < > " '` everywhere in text/attributes using `&amp; &lt; &gt; &quot; &#x27;`. Join block HTML with one newline.

Examples: body `**b** and *i*` renders `<p><strong>b</strong> and <em>i</em></p>`; `[**go**](https://example.org/a*b*)` renders `<p><a href="https://example.org/a*b*">**go**</a></p>`; `***x***` remains `<p>***x***</p>`; `[bad](javascript:alert)` remains `<p>[bad](javascript:alert)</p>`; a plain body containing a single quote renders `<pre>&#x27;</pre>`.
